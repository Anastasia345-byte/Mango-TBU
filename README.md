# Калькулятор ТБУ салона MANGO

Адаптивное веб-приложение для расчёта общей точки безубыточности салона, ТБУ услуг, индивидуальной ТБУ категорий мастеров, распределённой доли общей ТБУ и рекомендуемых цен.

## Возможности

- общая ТБУ бизнеса и отдельная ТБУ направления услуг;
- расчёт по направлениям и категориям мастеров;
- одновременный учёт процента мастера и фиксированной выплаты за услугу;
- минимальные и рекомендуемые цены;
- структура расходов и пять интерактивных графиков;
- автоматические проверки, выводы и рекомендации;
- сценарии в LocalStorage, импорт и экспорт JSON;
- мобильная адаптация.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Проверка

```bash
npm test
npm run build
```

Контрольные значения находятся в `src/data/control-data.json`. Допустимое отклонение — 1 ₽.

## Структура

- `src/lib/finance.ts` — вся финансовая логика, без React;
- `src/lib/finance.test.ts` — unit-тесты;
- `src/lib/schema.ts` — Zod-валидация;
- `src/data/example.ts` — демонстрационный сценарий;
- `src/components/dashboard.tsx` — интерфейс калькулятора;
- `src/app` — Next.js App Router.

## Логика двух показателей ТБУ категории

`Индивидуальная ТБУ категории` показывает самостоятельную безубыточность категории по её собственной маржинальности. Складывать эти показатели нельзя.

`Доля общей ТБУ услуг` распределяет общую ТБУ пропорционально выручке. Сумма долей всегда равна общей ТБУ услуг.

## Данные

MVP не имеет сервера. Финансовые данные сохраняются только в LocalStorage браузера и не передаются третьим лицам.
